# Roblox Drinking Animation and Prop

This project provides a drinking animation and a drink prop for Roblox Studio. The drinking animation script can be triggered by pressing the 'E' key or by touching a drink prop. The drink prop script creates a visual representation of a drink in the game world.

## Install

1. Download the project files.
2. Open Roblox Studio.
3. Insert the drinking animation and drink prop mesh into Roblox Studio.
4. Replace `YOUR_ANIMATION_ID` with the actual animation ID in the DrinkingAnimation script.
5. Replace `YOUR_MESH_ID` with the actual mesh ID in the DrinkProp script.
6. Place the `DrinkingAnimation.server.lua` script in the StarterPlayerScripts or StarterCharacterScripts folder.
7. Place the `DrinkProp.server.lua` script in the ServerScriptService folder.

## Use

1. Start the game in Roblox Studio.
2. Press the 'E' key to trigger the drinking animation.
3. Alternatively, touch the drink prop to trigger the drinking animation.
